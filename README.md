# Sign Language Recognition Robot 🤖

This project aims to develop a real-time system for recognizing sign language gestures using computer vision and machine learning.

## 🔬 Technologies
- Python
- OpenCV
- MediaPipe
- PyTorch (or TensorFlow)
- Git/GitHub

## 🎯 Goal
Real-time recognition of sign language gestures and conversion into text/speech.

## 🧠 Pipeline
Webcam -> Hand Tracking -> Feature Extraction -> ML Model -> Prediction -> Output
